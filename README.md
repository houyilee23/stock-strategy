## 系統概念

- **訊號模式**：每天對 watchlist 內每檔輸出 BUY/HOLD/SELL 建議
- **Tier**：S > A > B > C > D > F；F-tier 表示策略無利可圖，建議不持有
- **BS/BA/BB**：tier=F 但 BNH 長持期 CAGR 漂亮 → 改用「買進長持」替代
- **每檔 Template 不同**：每股獨立優化，由 `auto_iterate` 找出最佳策略 + 參數

詳見 [docs/](docs/) 與 [CLAUDE.md](CLAUDE.md)。
