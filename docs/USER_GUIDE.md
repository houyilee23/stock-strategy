# 台股個股策略系統 — 使用指南

## 1. 5 分鐘速懂系統

你現在有個自動化的台股策略系統。它做什麼？**每天檢查 17 檔「好股票」，告訴你進場時機**。

### Tier 五級制（你只需記住一件事）

| 等級 | 說明 | 部位上限 | 何時用 |
|------|------|----------|--------|
| **S** | 訊號最強的金牌股 | 100% | 可以放心交易，部位可到 1 倍 |
| **A** | 經過驗證、表現穩定 | 50% | 常規交易，部位 5 折以內 |
| **B** | 可用但要嚴格停損 | 30% | 謹慎交易，嚴格跟 trailing stop |
| **C** | 還在測試中 | 15% | **先紙上交易 3 個月**，看成績 |
| **F** | 不建議用 | 0% | 跳過，走組合模式或買 0050 |

### 部位怎麼算

簡單公式：

```
部位大小（張數）= 帳戶 equity × position_pct_max ÷ 股票現價

例：
帳戶 1,000,000 元
台積電（2330）Tier A，position_pct_max = 50% = 0.5
現價 820 元
張數 = 1,000,000 × 0.5 ÷ 820 ÷ 1000 ≈ 0.6 張
→ 實際下 600 股（取整數）
```

### 為什麼 C tier 要紙上交易 3 個月

C tier 股票樣本數少（通常只有 4-5 筆交易），容易過度擬合歷史。紙上交易 3 個月可以：
- 確認訊號在**活的市場**上是否真的有效
- 避免一上來就用真金白銀賭小樣本
- 3 個月後，對比紙面成績 vs. 系統預測，決定是否啟用真交易

## 4. Tier 分級制度懶人包

### 為什麼要分 Tier？

簡單說，**回測數據有好有壞**。系統用客觀指標把股票分級，讓妳知道「這檔能放多大部位」。

### 分級的三大指標

1. **PF_lower（下界 Profit Factor）**
   - 利潤因子 = 贏錢的總額 ÷ 賠錢的總額
   - PF ≥ 2.0 表示「平均每賠 1 元，贏 2 元」
   - PF_lower = bootstrap 信心區間的下界，越高越安心

2. **Expectancy（期望值）**
   - 每筆交易平均賺多少 %
   - 正數 = 長期有利潤；負數 = 長期會賠錢

3. **n_trades（樣本數）**
   - 回測期間內有幾筆交易
   - n < 5 = 樣本太少，容易過度擬合
   - n ≥ 8 = 比較有信心

### 五級一覽表

#### S 級（1 檔）
- **誰**：2317 鴻海
- **為什麼 S**：PF_lower = 2.72 ✓、exp = +8.4% ✓、n = 9 ✓、歷史驗證通過 ✓
- **能不能用**：✓ 完全可以用
- **部位上限**：100% → 帳戶最多 1 倍投入這檔

#### A 級（6 檔）
- **舉例**：2330 台積電、1560 中砂、2360 致茂、6770 力積電、2308 台達電、3017 奇鋐
- **為什麼 A**：PF_lower ≥ 1.5、exp ≥ 3%、n ≥ 6、至少一個歷史分段 pass
- **能不能用**：✓ 可以用
- **部位上限**：50% → 帳戶最多 5 折投入單檔

#### B 級（5 檔）
- **舉例**：1303 南亞、6515 穎崴、2454 聯發科、1802 台玻、3034 聯詠
- **為什麼 B**：PF_lower ≥ 1.0、exp ≥ 2%、n ≥ 5
- **能不能用**：✓ 可以用，但要嚴格 trailing stop
- **部位上限**：30% → 帳戶最多 3 折投入單檔
- **額外要求**：設定緊密的停損點，抓住快速出場的心態

#### C 級（5 檔）
- **舉例**：2383 台光電、1809 中釉、1326 台化、3711 日月光投控、2345 智邦
- **為什麼 C**：PF_lower ≥ 0.7、exp ≥ 1%、但樣本數少（3-4 筆）或其他風險因子
- **能不能用**：✗ 先不用真金白銀，改**紙上交易 3 個月**
- **部位上限**：15% → 紙上通過後才能開真倉，上限 1.5 折
- **為什麼有這限制**：樣本少 = 統計波動大，可能過度擬合歷史

#### F 級（22 檔）
- **誰**：不在上面 17 檔裡的那些（如 1227 佳格、1301 台塑、2002 中鋼等）
- **為什麼 F**：樣本數太少、期望值為負、或歷史驗證失敗
- **能不能用**：✗ 不建議單檔訊號模式
- **建議**：改用組合模式（top-N 配置）或直接買 0050

## 5. C Tier 紙上交易 3 個月怎麼執行

### 為什麼要紙上

C tier 股票回測時只有 3-4 筆成交。這麼少的樣本，風險包括：
- **過度擬合**：訊號對歷史數據很準，對未來不一定
- **運氣成分**：可能前 3 筆都賺錢是巧合

紙上交易就像「模擬賽」，3 個月內模擬交易，看看在**真實市場波動**下訊號表現如何。

### 怎麼做

#### 第一步：建立紙上交易表

新開 Excel，建立這個表格：

```
日期      股票  訊號  紙上進場價  實際開盤價  偏離 %  是否進場
2026-04-25  1809  BUY   12.30       12.45      +1.2%   Y/N
2026-04-26  1809  HOLD  (持有)
2026-04-27  1809  SELL  12.80       12.75      -0.4%   成交
```

欄位說明：
- **紙上進場價**：系統給的 entry 價
- **實際開盤價**：那天開盤時的真實股價
- **偏離 %**：差多少
- **是否進場**：（人腦判斷）考慮偏離、大盤、基本面後，妳真的會進場嗎

#### 第二步：每天記錄

每天 09:00 系統給訊號後：

```
1. 抓今日訊號（系統給）
2. 看實際股價（查盤軟體）
3. 填入 Excel
4. 記 3 個月（約 60 個交易日）
```

#### 第三步：3 個月後驗收

3 個月結束，對比：

```
紙上成績
==========
進場 5 次
贏錢 3 次
賠錢 2 次
勝率 60%
平均獲利 +8.2%

系統承諾
========
期望值 +15.9%（每筆）
PF 3.31（贏 / 賠 比）

評估
====
實際 60% 勝率 接近系統 PF 3.31（理論 75% 勝率）
實際 +8.2% 低於期望 +15.9%，但考量樣本少、大盤行情
→ 相符度 70%，可以開真倉，但部位先減半（從 15% → 7.5%）
```

決策邏輯：
- **相符度 ≥ 80%**：C 升等到 B，部位升到 30%（如果其他條件也對）
- **相符度 50-80%**：C 保持，但調整部位（如 15% → 8%）或加嚴格停損
- **相符度 < 50%**：保留在觀察名單，不啟用真交易

## 6. 出狀況怎麼辦

### 狀況 1：訊號 vs. 基本面打架

**例子**：系統給 2317 BUY，但鴻海昨天公布 Q1 獲利下滑 50%

**怎麼辦**：
1. 先跳過這個訊號（不進場）
2. 等基本面「消化完」（通常 1-3 個交易日）後，看下一個訊號

**原因**：訊號是基於過去資料的圖形判斷，遇到突發利空時，進場點位會變。與其硬進場跟隨停，不如等市場情緒穩定再重新看。

### 狀況 2：連續 3 次停損

**例子**：某檔股票上禮拜進場 3 次，全部在停損點止損

**怎麼辦**：
1. 該股票暫停 1 個月（不看訊號）
2. 1 個月後重啟

**原因**：連續停損可能代表「這個時期的行情不適合這檔股票的訊號」。暫停是避免連續出血。

### 狀況 3：大盤崩盤

**判斷標準**：
- 加權指數 1 天跌超 3%，且跌穿重要均線（如 20 日線）
- ATR（波動度）異常飆升（超過 6 個月均值 50% 以上）
- 新聞滿天飛：升息、戰爭、金融危機等黑天鵝

**怎麼辦**：
- **新進場的訊號**：全部暫停，等大盤穩定
- **已持有部位**：不是立刻出，而是
  - 如果停損點已破，執行停損
  - 如果還沒破，但近停損，可以主動降部位到 50% 以減少風險
  - 強勢股（Tier S）可以繼續持；弱勢股（Tier C）考慮先出

## 7. 名詞對照（非技術人版本）

| 名詞 | 一句話解釋 |
|------|-----------|
| **PF（Profit Factor）** | 贏錢總額 ÷ 賠錢總額。PF=2 表示平均每虧 1 元，賺 2 元 |
| **Expectancy** | 每筆交易平均能賺多少 %。+8.4% 表示一筆進出預期賺 8.4% |
| **Drawdown（最大回檔）** | 從高點跌到低點的幅度。-15% 表示最糟時虧了 15% |
| **Holdout** | 歷史驗證。把回測拆成 3 個時期（2010-2016、2018、2022），看在每個時期表現如何。都通過 = 歷史驗證穩定 |
| **Bootstrap CI（信心區間）** | 統計方法：如果訊號在 100 種洗牌方式下都還有賺，就越相信它是真的好訊號，不是運氣 |
| **Tier** | 訊號品質等級，從 S（最強）到 F（不用）|
| **Trailing Stop** | 跟蹤停損。股票上升時，停損點也往上，鎖定部分利潤 |

## 8. 進階：自己跑回測驗證

如果妳想驗證系統的回測數據，可以自己跑一遍。

### 指令

```bash
'C:/Users/houyi.lee/AppData/Local/anaconda3/python.exe' main.py backtest \
  --list Takeshi \
  --start 2017-01-01 \
  --end 2024-12-31
```

這會跑 2017-2024 八年的回測。

### 看結果

終端會輸出（舉例）：

```
=== 2317 鴻海（Tier S）===
進場次數：9
贏錢次數：7
賠錢次數：2
勝率：77.8%

平均獲利：+8.4%
最大連續虧損：-15.1%
PF（profit factor）：11.47

結論：ROBUST — 直接用
```

### 怎麼讀

- **進場次數 n**：越多越好（>8 比較安心）
- **勝率**：不是最重要（50% 勝率但 PF 高的訊號也很強）
- **平均獲利（Expectancy）**：這是妳每進一次場預期賺多少
- **最大連續虧損（Max DD）**：做心理準備，最糟會跌這麼多
- **PF（利潤因子）**：PF > 2 算強，> 1.5 算不錯，< 1 會虧錢

## 常見問題

**Q1：我部位限制搞不懂，怎麼算？**

A：用計算機直接算。例：
```
帳戶：500,000 元
股票：2330（台積電），Tier A，部位上限 50%
現價：820 元
張數 = 500,000 × 0.5 ÷ 820 ÷ 1,000 = 0.30 張
取整 = 300 股（≈ 0.3 張）
```

**Q2：訊號給出 BUY，但我覺得貴，要不要等？**

A：訊號考慮的是圖形 + 技術指標，不是「便宜貴」。如果開盤價在 entry_low～entry_high 區間內，就是「訊號價」，可以進。如果已經超出區間，就跳過這次。不用自己預測會不會跌。

**Q3：A tier 和 B tier 差在哪？**

A：B tier 風險更高（樣本少 or 波動大），所以：
- A tier：正常操作，部位 50% 上限
- B tier：同樣部位 30%，但一定要設 trailing stop，抓住快速出場

**Q4：我想加新股票進來，怎麼做？**

A：系統會自動跑 auto_iterate 分級。妳只需在 `config/watchlists.yaml` 新增股票代碼，下次更新時系統會抓進來。不要手動改 tier，讓系統判斷。

**Q5：停損後還要再進嗎？**

A：取決於訊號。如果停損出場，隔一天同檔股票又給 BUY，妳可以重新進場。系統不禁止「打回來再進」。但如果連續 3 次停損，就暫停 1 個月。

**Q6：紙上交易 3 個月太久，能不能快速開真倉？**

A：可以，但我建議初期先跑 3 個月。妳會更了解「訊號在真實市場的表現」和「妳自己對波動的心理承受度」。而且 C tier 都是高期望值的股票（+15.9% ~ +18.5%），多等 3 個月不虧。
