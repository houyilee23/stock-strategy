## 提案的訊號規則（這次驗證的目標）

**進場（4 條件全滿足）**：
1. 個股：close > MA60
2. 籌碼：過去 5 個交易日「外資 + 投信」累計買超 > 0，**且**今日是其中一天
3. 價格：close > 過去 20 日最高 × 0.98
4. 大盤：0050 close > MA60

**時間防穿越**：
- 籌碼資料是 T 日盤後公布 → 算 T 日訊號時只能用 T-1 及以前的籌碼
- T 日訊號 → 隔天 T+1 開盤成交（既有規則）

## 實作細節

### 檔案位置
`scripts/validate_chip_signals.py`

### 5 檔測試股
```python
SIDS = ["2330", "3017", "6669", "2454", "2317"]
START = "2013-01-01"   # FinMind 籌碼資料約 2012-05 起，留 1 年預熱
END = "2026-04-22"
```

### FinMind dataset
```
TaiwanStockInstitutionalInvestorsBuySell
```

預期欄位（請實測確認）：
- `date`
- `stock_id`
- `name` — 機構別（如 `Foreign_Investor`, `Investment_Trust`, `Dealer_Self`...）
- `buy` — 當日買進股數
- `sell` — 當日賣出股數

**注意**：原始資料是「長表」（每日每機構一列），需要 pivot 成「每日一列、各機構分欄」再算 `外資 + 投信淨買超 = (Foreign_buy - Foreign_sell) + (InvTrust_buy - InvTrust_sell)`。

機構名稱實際字串可能不一樣，先 print `df['name'].unique()` 確認。

### 處理流程
```
for sid in SIDS:
    1. fetch chip data (一次抓全期)
    2. pivot 成每日 (foreign_net, trust_net)
    3. shift(1) — 因為 T 日策略只能用 T-1 籌碼
    4. 載入 data/adjusted/{sid}.csv 的 close
    5. 計算 MA60, 過去 20 日 rolling max
    6. 計算「外資+投信」過去 5 日累計
    7. 載入 0050 並算 MA60 當大盤過濾
    8. 套 4 個條件 → 印出符合的日期清單
```

### 輸出格式（給使用者肉眼看）

對每檔個股印一張表：
```
======================================================================
  2330 台積電  訊號清單
======================================================================
  日期         close   MA60    20D高  外資5日  投信5日  合計5日
  2014-03-21   125.5   118.2  126.0   +18234  +3201   +21435
  2014-08-15   132.0   125.4  133.5   +9821   +2104   +11925
  ...
  
  共 N 個訊號  (年化 N/13 = X.X 次)
```

買超數字單位是「張」（買進股數 / 1000），方便閱讀。

### 在最後印一個 summary
