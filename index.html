📖 符號說明

動作

  • 🔴 BUY — 進場訊號（台股配色：紅 = 多/漲）
  • 🟢 SELL — 出場訊號（綠 = 空/跌）
  • HOLD — 觀望，無進出建議

掛單（限價單機制 v0.1，目前 low_vol_pullback / mean_reversion 才有）

  • 買 X → 隔日預掛限價買在 X 元，盤中觸及才成交
  • TP X / SL Y → 在倉建議：TP（Take Profit，停利）X 元觸及就賣；SL（Stop Loss，停損）Y 元跌破就賣
  • — → 該標的無限價單訊號（其他 template 預設 T+1 開盤市價成交）

Tier（策略信心等級）

  • S — 最高信心（倉位上限 100%）
  • A — 高信心（倉位上限 50%）
  • B — 中等信心（倉位上限 30%）
  • C — 普通信心（倉位上限 15%）
  • F — 策略無利可圖，不建議持有
  • BS / BA / BB → BNH_S/A/B 長持替代（tier=F 但長期買進長持有效）
  • * → 倉位來自 BNH 評估

趨勢與 RSI

  • ▲ 多 — 多頭排列（Close > MA200 且 MA50 > MA200）
  • ▼ 空 — 空頭排列
  • RSI 🔥 — 過熱（≥75，警告超買）
  • RSI ❄️ — 過冷（≤30，可能反彈）

在倉狀態

  • ✅ — 真實持有（從 trades_帳戶.csv 推算）
  • · — 未持有 / 觀察中

Regime（大盤環境）

  • BULL — 大盤多頭（0050 在 MA200 之上）
  • BEAR — 大盤空頭
  • NEUTRAL — 中性

策略由 auto_iterate 對每檔獨立優化 · Tier 越前面信心越高 · F-tier 不建議持有
